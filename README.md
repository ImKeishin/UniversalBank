# UniversalBank
&nbsp;&nbsp;&nbsp;&nbsp;This project is about a Universal Bank that has a growing customer base. Most of these customers are depositors with different deposit values. The number of customers who are also debtors (customers who borrow) is quite small, and the bank is interested in quickly expanding this base to bring more loans by increasing the interest winnings. The bank's strategy is to explore ways to attract customers to access personal needs (personal loan). A campaign that the bank carried out last year for deposit customers showed a conversion rate of over 9% successful.
&nbsp;&nbsp;Next the department wants to build a model that will help them identify potential customers who have a higher probability of purchasing personal needs.                                                              
&nbsp;&nbsp;&nbsp;&nbsp;This Machine Learning Project uses a logistic regression model with different solvers to determine if a bank customer would access a personal loan. 

To run this program you first need to have Python installed
Open a terminal window and type the following commands:

python -m venv sklearn-env
sklearn-env\Scripts\activate  # activate
pip install -U scikit-learn
pip install numpy
pip install pandas
pip install matplotlib.pyplot
pip install seaborn
pip install jupyter notebook
jupyter notebook

Now you only need to navigate to the cloned repository on your local machine (this web app is similar to the file explorer) and double click the file called "Project.ipynb"
